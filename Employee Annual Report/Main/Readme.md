👩‍💼 Employee Yearly Overview – Power BI Dashboard

📌 Project Overview

An interactive Power BI dashboard designed to provide insights into employee performance, work mode trends, department efficiency, training certifications, and workforce distribution.

🧪 Disclaimer

📌 Note: The data used in this project was entirely self-generated using GenAI tools and does not represent any real-world individuals, companies, or entities. It was created purely for learning and demonstration purposes.

🎯 Key Features

KPI cards for attendance, efficiency, bonuses, and more

Department-wise analysis: task completion, efficiency

Monthly employee trend line

Work mode breakdown (Remote, On-site, Hybrid)

Filters for department, manager, work mode, etc.

📊 Dashboard Preview



📁 Data Source

Simulated employee HR data in Excel format

Created manually using GenAI tools for the purpose of demonstration

Contains columns for: department, efficiency, attendance, certifications, trainings, etc.

Power BI Desktop

🚀 How to Use

Clone the repo or download the .pbix file.

Open in Power BI Desktop.

Load the dataset from the data/ folder if needed.

Explore and filter the dashboard interactively.
